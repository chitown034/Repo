# Hormozi Offer Workbench

A single-file dashboard for running the seven "$100M Offers" style prompts against your own offer.

Open `index.html` in any browser. Paste your offer, target audience and launch context once; all seven prompts fill themselves in. Each card has a copy button, a place to paste Claude's answer, and a Done checkbox. The sidebar also scores your offer with the Value Equation (Dream Outcome × Perceived Likelihood ÷ Time Delay ÷ Effort & Sacrifice).

Everything is saved in the browser's local storage only.
