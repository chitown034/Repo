How this works

Each device gets the same three doors. Claude — its Claude Code session shows up in your session list (Remote Control). Orca — all your AI agents on that machine, paired over your private network. AnyDesk — see and use the whole screen. Tick a step when it is done; the ring fills. Nothing here stores a password, key or pairing link: AnyDesk IDs and ticks live only in this browser.

Paste a status line (optional)

The install scripts print one line of status words (no secrets). Paste it here and the matching device card updates. A line that contains anything that looks like a key, password or link is refused.

Rules that never change

  • A pairing link or an AnyDesk password is the same as the keys to that computer. Never paste one into chat, a note, this page or the repo.
  • Pair Orca only over your home network or Tailscale. Desktop control is never granted through Orca.
  • An agent can read, search and draft on any device. Sends, spending, signing and account changes still wait for you.
