## How to deploy a question

1. **Page or FAQ entry** on the hub (`site/`) or temeculahomefinder.com with the question as an H2 and the opener as the first paragraph.
2. **FAQPage JSON-LD** entry (see `schema/faq.jsonld`) with the same wording.
3. **A 30–60s vertical video** answering it (YouTube Short, Reel, TikTok) with the question as the on-screen title and the first spoken line.
4. **A GBP post and Q&A entry** with the same text.
5. **One forum answer** (Reddit/Nextdoor) where the question is actually being asked.
Same wording in all five places is the point: repetition across sources is what LLMs read as consensus.
