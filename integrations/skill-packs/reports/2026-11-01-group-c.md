## Code Mode: which of the three apply to Steven

"Code Mode" means the AI writes a small script that calls many tools at once, instead of calling them one
by one. It saves tokens when there are many tools.

1. **Cloudflare Code Mode MCP (`https://mcp.cloudflare.com/mcp`) and `cloudflare/agents/packages/codemode`.** It does not apply now.
   The MCP server is Cloudflare's own API server: it lets an agent manage a Cloudflare account (DNS, Workers
   and so on) through two tools, search and execute. You sign in to it with a **Cloudflare account**, and nothing in
   the brain shows he has one. The `codemode` package is a developer library (marked "Experimental") for
   people building their own agents on Cloudflare Workers. It is not something you switch on in Claude Code. **HOLD.**
   If he ever has a Cloudflare account and wants Claude to manage it, the one-line add is
   `claude mcp add --transport http cloudflare https://mcp.cloudflare.com/mcp`. It asks him to sign in to Cloudflare in the browser, and no key is pasted.
   (Cloudflare's docs site was not reachable from this session, so this rests on the repo and general knowledge.)
2. **Claude API programmatic tool calling (`"type": "code_execution_20260120"` plus `"allowed_callers"`).** It does not apply.
   It is a feature of the **Claude API** for apps that call Anthropic directly with an API key: you mark a
   tool with `"allowed_callers": ["code_execution_20260120"]` and Claude can call it from inside a code-execution
   container. Claude Code on his subscription does not use this setting, and he has nothing to configure. It would
   matter only if Derek someday builds a custom app on the API. That means an API key and paid usage, so it is HOLD at that point.
   Anthropic's docs also warn that `allowed_callers` is **not a security boundary**, and that data is kept up to 30 days, so it is not eligible for zero data retention.
3. **goose (Block) Code Mode toggle.** It does not apply. It is a setting inside goose, a different coding
   agent (enable it with `goose configure` → Toggle Extensions → `code_execution`). Installing goose would be a duplicate
   coding agent, which was declined before. **DECLINE.**

There is no config snippet to apply today: none of the three is installable for him as things stand.
