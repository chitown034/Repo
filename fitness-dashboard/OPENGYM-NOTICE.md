# openGym attribution

`opengym-index.json` is a compact index (exercise id, name, body part, equipment, target muscle,
secondary muscles, category) generated from the exercise catalogue of
**openGym** by Duarte Santos: https://github.com/DuarteSantos8/openGym

- openGym's own code and the catalogue text written for it are licensed under the
  **GNU AGPL v3.0** (https://www.gnu.org/licenses/agpl-3.0.html).
- Entries marked `textSource: "exercisedb"` in the catalogue (names and muscles) originate from
  ExerciseDB v1 via hasaneyldrm/exercises-dataset under the **MIT License**.
- **No exercise images, animations or videos are included.** openGym's media is licensed to openGym
  by Gym visual (gymvisual.com) for use inside the openGym app only and must not be copied or reused.
- The index contains no descriptions or instructions, only the factual tags above.

Because this index is derived from AGPL-licensed data, keep this notice with it and, if you
redistribute the dashboard, make the corresponding source (this repository) available under the AGPL.
